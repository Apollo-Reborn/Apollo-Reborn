# Find in Comments simulator evidence

`find-in-comments.gif` shows the post-detail Liquid Glass menu opening Find in
Comments, the native search field becoming active, and a query producing a
match count plus an in-thread highlight.

The recording was made in an iOS 27.0 simulator with a customized action-menu
layout. The same build was also checked with the untouched default layout. A
separate regression pass advanced from match 1 of 4 to match 2 of 4 with the
Next control.

This is simulator evidence only. No real-device test or installation was
performed for this change.
